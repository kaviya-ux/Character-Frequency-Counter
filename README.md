# 🔤 Character Frequency Counter

A simple **Character Frequency Counter** web application built using **HTML, CSS, Tailwind CSS, and JavaScript**.

The application takes a text input from the user and counts how many times each character appears in the given text.


## 📌 Features

* Enter any text in the input field
* Count the frequency of each character
* Display the character and its occurrence count
* Simple and beginner-friendly interface
* Responsive design
* Built using JavaScript without any external backend

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling
* **Tailwind CSS** – Responsive and utility-based styling
* **JavaScript** – Character counting logic

## ⚙️ How It Works

1. The user enters a text or sentence.
2. JavaScript reads the entered text.
3. Each character is checked one by one.
4. The program keeps track of how many times each character appears.
5. The final character frequency is displayed on the webpage.

### Example

**Input:**

```text
hello
```
**Output:**

```text
h : 1
e : 1
l : 2
o : 1
```
